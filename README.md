# Portfólio

Site de portfólio estático desenvolvido com Vue 3 e Vite. A página tem navegação por âncoras e seções para apresentação, projetos, experiência e contato.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build de produção

```sh
npm run build
npm run preview
```

Edite `src/App.vue` para atualizar textos, projetos, experiência e links. Os estilos globais e responsivos ficam em `src/style.css`.
